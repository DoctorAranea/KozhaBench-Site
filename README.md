# Сайт LeatherDraft

Страницы сайта программы LeatherDraft: обычные HTML и CSS, без сборки. GitHub Pages показывает их как есть.

## Что где

- `index.html`, `first-steps.html`, `whats-new.html` - русские страницы: главная, первые шаги и что нового.
- `en/` - те же страницы по-английски.
- `assets/site.css` - оформление в цветах программы, тёмная и светлая тема.
- `assets/site.js` - переключатель темы; выбор запоминается в браузере.
- `assets/releases.js` - берёт выпуски с GitHub прямо в браузере посетителя: все версии на странице "Что нового",
  номер, дата и первые пункты последней версии на главной. Из описания выпуска показывается часть на языке
  страницы: до черты `---` - русская, после - английская.
- `assets/logo.svg`, `assets/favicon.svg` - знак программы.
- `assets/img/ru`, `assets/img/en` - снимки экрана.
- `.nojekyll` - чтобы GitHub Pages не пропускал файлы через свой обработчик.

## Как опубликовать

1. Залейте файлы в ветку `master`.
2. В репозитории на GitHub: "Settings" - "Pages", в "Source" выберите "Deploy from a branch", ветку `master`
   и папку `/ (root)`, нажмите "Save".
3. Через минуту-две сайт откроется по адресу `https://doctoraranea.github.io/LeatherDraft-Site/`.

## Как посмотреть до публикации

Откройте `index.html` двойным щелчком - страницы работают и без сервера.

## Что обновлять при выпусках

Ссылка "Скачать" всегда ведёт на последний установщик, а "Что нового" и номер версии на главной берутся с GitHub
сами - их менять не нужно. Новые возможности - в карточках раздела
"Что умеет" на обеих главных страницах, новые снимки - в `assets/img` и в разделе "Как это выглядит".
